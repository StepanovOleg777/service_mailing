# Сервис управления рассылками

Веб-приложение для управления email-рассылками, созданное на Django.

## Функциональность

### Часть 1
- Управление клиентами (CRUD)
- Управление сообщениями (CRUD)
- Управление рассылками (CRUD)
- Отправка сообщений по требованию
- История попыток отправки
- Главная страница со статистикой

### Часть 2
- Регистрация и аутентификация пользователей
- Статистика и отчеты по рассылкам
- Ограничение доступа (пользователи/менеджеры)
- Кеширование данных
- Автоматическая отправка рассылок
