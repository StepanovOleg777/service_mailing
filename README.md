# 📧 Сервис управления рассылками
Веб-приложение для управления email-рассылками, созданное на Django. Позволяет пользователям создавать клиентскую базу, шаблоны сообщений и управлять рассылками с автоматическим отслеживанием статистики.

## 🚀 Возможности
### Часть 1: Основной функционал
✅ Управление клиентами — CRUD операции для базы получателей

✅ Управление сообщениями — создание и редактирование шаблонов писем

✅ Управление рассылками — планирование и запуск email-кампаний

✅ Автоматический статус рассылок — "Создана", "Запущена", "Завершена"

✅ Отправка писем — ручной запуск через интерфейс и командную строку

✅ История попыток — отслеживание успешных/неуспешных отправок

✅ Статистика на главной — обзор активности по рассылкам

### Часть 2: Расширенный функционал
✅ Аутентификация пользователей — регистрация, вход, выход

✅ Кастомизированная модель пользователя — с дополнительными полями

✅ Права доступа — пользователи видят только свои данные

✅ Кеширование — повышение производительности через Redis/LocMemCache

✅ Группа менеджеров — специальные права для администрирования

## 🛠 Технологии
Backend: Django 4.2, PostgreSQL/SQLite

Frontend: Bootstrap 5, Crispy Forms

Кеширование: Redis (опционально LocMemCache)

Отправка email: Django SMTP/Console backend

Форматирование кода: Black, Flake8

Контейнеризация: Docker (опционально)

## 🚀 Быстрый старт
1. Клонирование и настройка
git clone <repository-url>
cd service_mailing
python -m venv venv
source venv/bin/activate  # Linux/Mac
### или
venv\Scripts\activate     # Windows

2. Установка зависимостей
pip install -r requirements.txt

3. Настройка окружения
cp .env.example .env

 Отредактируйте .env файл под вашу конфигурацию
4. База данных и миграции
 Для PostgreSQL (рекомендуется)
createdb mailing_db

### Или используйте SQLite (для разработки)
### Не требует дополнительной настройки

### Применение миграций
python manage.py migrate
5. Создание суперпользователя и групп
python manage.py createsuperuser
python manage.py create_groups

6. Запуск сервера
python manage.py runserver
Откройте http://localhost:8000 в браузере

## ⚙️ Настройка email
По умолчанию используется консольный бэкенд для разработки. Для реальной отправки настройте в .env:

env
### Для Яндекс.Почты
EMAIL_HOST=smtp.yandex.ru
EMAIL_PORT=587
EMAIL_HOST_USER=your-email@yandex.ru
EMAIL_HOST_PASSWORD=your-app-password
EMAIL_USE_TLS=True
DEFAULT_FROM_EMAIL=your-email@yandex.ru

### Для разработки (письма в консоль)
EMAIL_BACKEND=django.core.mail.backends.console.EmailBackend
